Pengaturan Google OAuth 2.0

Untuk mengaktifkan dialog popup akun resmi dari accounts.google.com, masukkan Client ID dari Google Cloud Console:

💡 Cara Buat Google Client ID (100% Gratis):
  1. Buka console.cloud.google.com
  2. Pilih APIs & Services > Credentials
  3. Klik Create Credentials > OAuth client ID
  4. Pilih Application type: Web application
  5. Tambahkan URL domain Anda ke Authorized JavaScript origins
  6. Salin Client ID dan tempelkan di atas!

Cara Pasang di Layar HP Anda

Hanya 2 langkah mudah tanpa download dari PlayStore/AppStore!

Jika Anda Pakai Android (Chrome):
  1. Ketuk menu titik tiga (⋮) di pojok kanan atas browser.
  2. Pilih menu "Instal aplikasi" atau "Tambahkan ke Layar utama" ➕.
Jika Anda Pakai iPhone (Safari):
  1. Ketuk tombol Share (Bagikan) di bagian bawah Safari.
  2. Geser ke bawah, lalu pilih "Tambahkan ke Layar Utama" (Add to Home Screen) ➕.
