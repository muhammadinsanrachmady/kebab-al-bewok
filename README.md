# 🍢 Kebab AL Bewok - Live Cloud WebApp 24/7

Ekosistem lengkap aplikasi Kebab AL Bewok (Customer, Driver/Kurir, Admin Dapur Lapak, dan Portal Owner).

---

## 🚀 Deploy 1-Klik ke Cloud (100% Gratis & Aktif 24 Jam Tanpa Perlu Laptop Nyala)

### Opsi A: Render.com (Direkomendasikan - Paling Stabil untuk Node.js)
Klik tombol di bawah ini untuk deploy otomatis ke cloud Render:

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/muhammadinsanrachmady/kebab-al-bewok)

1. Klik tombol di atas atau buka tautan:  
   👉 **[https://render.com/deploy?repo=https://github.com/muhammadinsanrachmady/kebab-al-bewok](https://render.com/deploy?repo=https://github.com/muhammadinsanrachmady/kebab-al-bewok)**
2. Masuk menggunakan akun **GitHub** Anda.
3. Klik tombol biru **"Apply"** / **"Create Web Service"**.
4. Tunggu ~1 menit, Render akan memberikan link HTTPS permanen, contoh:  
   `https://kebab-al-bewok-xxxx.onrender.com/customer`  
   *(Link ini aktif 24 jam nonstop meskipun laptop Anda dalam keadaan mati).*

---

### Opsi B: Vercel
1. Buka [https://vercel.com/new](https://vercel.com/new).
2. Pilih repositori `muhammadinsanrachmady/kebab-al-bewok`.
3. Klik **"Deploy"**.
